## 3. 運用ルール

1. **改版規律**: 確定事項の変更は、変更する文書の改版(変更点の記録)+影響を受ける文書の更新を必ず行う
2. **決定記録**: プロダクトオーナーの判断は「決定内容/根拠/影響」の形式で該当文書に記録する(01冒頭・04冒頭の形式に倣う)
3. **未決ID体系**: 製品レベルは01がD-xx、技術は各文書がローカルIDを持つ(04=D-A / 05=D-B / 06=D-C / 07=D-D / 10=D-E / 11=D-F)。解消したIDは再利用しない
4. **参照表記**: 文書間参照は「文書番号 §節番号」(例: 01 §8)に統一する。節番号ではなく項目名で引く場合は#番号(02の対応表)かID(D-xx)を使う
5. **実装の正**: コードの挙動と文書が乖離したら文書を正として修正する(修正のコストが不当な場合のみ、文書改版で裁定する)
