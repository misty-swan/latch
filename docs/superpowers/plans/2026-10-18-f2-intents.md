## Review Focus

1. **つながりIntentにstarts_at・alcohol_involvedが付いたままactive化** — 400 VALIDATION_FAILED(details.reasonsに理由コード)で拒否 → Task 2・4のテスト
2. **機会Intentのstarts_atが過去・またはnow+7日超** — 400(理由コードstarts_at_out_of_range)→ Task 2のテスト
3. **期限の既定計算** — つながり=active化時刻+30日(7/90も可・明示expires_atは拒否)/機会=既定start+3時間(明示指定可・startより後であること)→ Task 2・4のテスト
4. **他人のIntentの取得・更新・削除** — 一律404で存在を隠す(一覧にも混入しない)→ Task 5のテスト
5. **ACTIVE_INTENT_LIMIT(5件)** — 作成(active直行)・draft→active・resumeの3経路すべて422 → Task 6のテスト
